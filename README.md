# online-price-watch

A simple tool to monitor online prices and send alerts when they change.

## Features

- Track prices from configurable product URLs
- Send notifications when price thresholds or changes occur
- Store historical price data for analysis

## Getting started

1. Clone the repository:

   git clone https://github.com/HoHoHo8/online-price-watch.git
   cd online-price-watch

2. Install dependencies (example for Node.js / Python - update based on project):

   - Node.js (npm/yarn):
     ```bash
     npm install
     ```

   - Python (pip):
     ```bash
     pip install -r requirements.txt
     ```

3. Configure the tracker (create a config file or set environment variables):

   - Add product URLs and alert thresholds to config.json or use environment variables as documented in the project.

4. Run the tracker:

   - Node.js example:
     ```bash
     npm start
     ```

   - Python example:
     ```bash
     python main.py
     ```
